# Windows 使用指南 · Rust v0.5.2

这个程序把 MIDI 中的音符安排成视频：当前有几个音符同时播放，就同时显示几个素材；每个音符结束时，该格视频和它的原声一起停止。也可以生成音名、频率、力度卡片，或只导出 WAV 音频。

**第一次使用，先按下面的“快速跑通一次”操作。运行成品不需要安装 Python、Rust 或开发工具。**

## 1. 下载并解压

打开 [Rust v0.5.2 发布页](https://github.com/DdRusher/midi_videostitcher/releases/tag/rust-v0.5.2)，在页面底部的 **Assets** 中下载：

| 文件 | 用途 |
| --- | --- |
| [midi_videostitcher-rust-0.5.2-windows.zip](https://github.com/DdRusher/midi_videostitcher/releases/download/rust-v0.5.2/midi_videostitcher-rust-0.5.2-windows.zip) | Windows 64 位程序包，必须下载 |
| [sine_test_MIDI_0_127_5s.zip](https://github.com/DdRusher/midi_videostitcher/releases/download/rust-v0.5.2/sine_test_MIDI_0_127_5s.zip) | 可选测试素材：C-1～G9，共 128 个音高，每个 5 秒；附测试 MIDI |

发布页自动生成的 **Source code (zip)**、**Source code (tar.gz)** 是源码，不能代替含 EXE 的程序包。本次发布的 Windows 包面向 **Windows 10/11 x64**。

把两个 ZIP 分别解压到普通文件夹，例如“文档”里的工作目录。**先解压，再启动，不要直接在 ZIP 里双击运行。** 程序目录应包含：

```text
midi_videostitcher-rust-0.5.2/
├─ start.bat
├─ start-rust.bat
├─ 开始使用.txt
├─ native/
│  ├─ midi-videostitcher.exe       ← 中文窗口
│  └─ midi-videostitcher-rust.exe  ← 命令行入口
└─ docs/
```

双击 `start.bat`，也可以直接打开 `native/midi-videostitcher.exe`。如果已经开着旧版本，关闭旧窗口后再启动这个包，右上角版本应为 **v0.5.2**。

## 2. 准备运行环境

### 启动窗口：Visual C++ v14 x64 运行库

本次发布包由 Windows 构建流程编译，需要微软 **Visual C++ v14 x64 运行库**。如果窗口已经能正常打开，继续下一步即可；如果双击没有打开窗口，或提示缺少 `VCRUNTIME140.dll`，请从微软安装运行库后重试：

- [微软官方说明与下载页](https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist?view=msvc-170)
- [微软官方 x64 运行库安装包](https://aka.ms/vc14/vc_redist.x64.exe)

运行库负责让程序启动，下面的 FFmpeg 负责处理媒体，两者用途不同。不需要安装 Visual Studio、Rust 或 Python；也不要从第三方 DLL 下载站单独寻找 `VCRUNTIME140.dll`。

### 处理素材：FFmpeg

**程序包没有捆绑 FFmpeg。** 它负责读取素材和编码成片；电脑已经能自动找到 FFmpeg 时，无需重复安装。

如果出现“找不到 FFmpeg”，可以这样配置，不必修改系统 PATH：

1. 从 [FFmpeg 官方下载入口](https://ffmpeg.org/download.html) 进入 Windows 构建下载页；也可直接访问 [Gyan Windows 构建页](https://www.gyan.dev/ffmpeg/builds/)。
2. 在 Gyan 页的 **release builds** 下选择 [ffmpeg-release-essentials.zip](https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip)。这里需要的是 Windows 可执行程序包，不是 FFmpeg 源码，也不需要 shared 开发包。该构建页提供 `ffmpeg`、`ffprobe`、`ffplay`；常用媒体功能包含在 essentials 构建中。[构建包说明](https://www.gyan.dev/ffmpeg/builds/#about-these-builds)
3. 解压 FFmpeg ZIP，在其中的 `bin` 文件夹找到 `ffmpeg.exe` 和 `ffprobe.exe`，把这两个文件复制到程序的 **native 文件夹**，与 `midi-videostitcher.exe` 放在一起。

```text
native/
├─ midi-videostitcher.exe
├─ midi-videostitcher-rust.exe
├─ ffmpeg.exe   ← 自行下载后放入
└─ ffprobe.exe  ← 自行下载后放入
```

另一种方法：在程序的 **“03 声音与输出” → “更多设置” → “选择 FFmpeg”** 中，直接选择解压得到的 `ffmpeg.exe`。让 `ffprobe.exe` 留在它旁边即可。Windows 版试听使用系统声音接口，不要求安装 FFplay。

## 3. 快速跑通一次

测试素材解压后应有 `videos`、`wav`、`tests` 三个子文件夹。`videos` 内是带正弦原声的 MP4，`wav` 内是对应音频，二者分开放置。

1. 在 **“01 导入与选区”** 点 **“选择 MIDI”**，打开素材包中的 `tests/test_overlap.mid`。这是约 11 秒的测试，包含重叠音符和力度变化。
2. 点 **“选择目录”**，选择素材包的 **videos** 文件夹。标准素材包也可以直接选择外层文件夹，程序会识别里面的 `videos`。
3. 点 **“读取 MIDI”**，再点 **“检查所选素材”**。保持 **“跟随延音踏板”不勾选**。
4. 切到 **“03 声音与输出”**。声音来源选择 **“素材原声混音”**，画面模式选择 **“原视频素材分屏”**；先用 **1280 × 720、30 fps、全部同时音符**。
5. 点底部 **“试听选区”** 检查声音；可点 **“停止试听”**。试听会先生成整个选区的音频，长选区需要等待，可以取消。
6. 点 **“选择位置”**，保存为一个新的 `.mp4` 文件；点 **“导出视频 MP4”**。完成后点 **“打开结果”** 或 **“打开目录”**。

如果想按顺序检查全部音高，将 MIDI 换成 `tests/test_all_notes.mid`：它依次播放 128 个音符，每音 0.5 秒，总长 64 秒。每份源素材仍完整保留 5 秒。

## 4. 制作自己的 MIDI

### 选择轨道和时间

读取 MIDI 后，有音符的轨道默认全选。勾选需要的轨道，也可限制通道；不需要的声部取消勾选即可。

“开始”“结束”支持秒数、`分:秒`、`时:分:秒`，例如开始 `0:30`、结束 `0:45` 就只制作这一段。结束留空表示 MIDI 结尾。也可以拖动时间轴选区或边界；**“选择全曲”** 恢复完整范围。

先选 10–20 秒试做，确认声音、素材和画面合适后再导出全曲。改变选区、素材或声音设置会停止当前试听，下一次试听使用新的设置。

### 准备自己的素材

每种需要的音高对应一份素材，按音名或 MIDI 编号命名，例如：

```text
我的视频素材/
├─ C4.mp4     ← MIDI 60
├─ C#4.mp4    ← MIDI 61，也可用 Db4.mp4
└─ E4.mp4     ← MIDI 64
```

只导出声音或生成音名画面时，也可以用同名 WAV、FLAC、MP3 等音频素材。**同一个目录、同一种音高只保留一份候选**，不要把 `C4.wav` 和 `C4.mp4` 混在一起，也不要同时放 `C#4.mp4`、`Db4.mp4` 和 `61.mp4`。

程序按 **MIDI 60 = C4** 匹配音高，不按乐器名称自动生成声音。它使用你提供的原声；视频素材分屏需要有视频轨道的文件。MIDI 所用的每一种音高都要有对应素材。

自己的素材请直接选择包含音名文件的文件夹。标准正弦包的外层自动识别只适合它原本的目录结构；如果后来把成片或其他音视频放在包根目录，请直接选择 `videos`，并把导出结果保存到素材目录之外。

### 每个素材选哪一段

打开 **“02 素材片段”**，点 **“检查所选素材”**，再点表格中的某一行。表格列出素材时长、当前选区的最长需求及已有设置。

- **固定片段**：例如源素材 5 秒，开始填 `1`、结束填 `3`，就从素材第 1–3 秒取材；结束留空表示素材末尾。点 **“应用到此素材”** 保存。
- **随机选段**：勾选 **“随机选段”**，设置允许使用的范围，再点 **“应用到此素材”**。范围能容纳音符时，程序在范围内挑选起点。
- **批量设置**：**“应用到全部素材”** 会把同一设置应用到当前需要的素材，范围必须对每份素材都有效。**“重置此素材”** 恢复当前音高的默认设置。
- **重新抽取**：点 **“重新随机”** 更换随机编号。相同 MIDI 选区、素材设置和随机编号下，试听与导出使用相同的片段。

音符比选定素材片段长时，只在选定范围内循环，不会播放到范围外。长音不会因为其他音符进入、退出或网格重排而从头播放。

## 5. 选择声音、画面与导出类型

| 你想要的结果 | 设置方法 |
| --- | --- |
| 原视频分屏，保留各素材原声 | “素材原声混音”＋“原视频素材分屏” |
| 看音名、Hz、力度，听素材原声 | “素材原声混音”＋“音名 / 频率 / 力度（快速）” |
| 已有 MIDI 和一整首录音，录音配音名画面 | “导入整段音乐” → “选择音频”＋“音名 / 频率 / 力度（快速）”；此组合不需要音高素材目录 |
| 只要声音 | 设置好声音来源后，点底部“导出音频 WAV”；会另选 WAV 保存位置，不渲染视频 |

**素材原声混音不额外添加背景配乐。** 启用 **“按 MIDI 力度控制音量”** 后，声部按力度保留强弱，127 为原音量系数、64 约为一半；声音重叠时叠加，并对最终峰值限幅。

“导入整段音乐”会用该音乐替代素材混音。音乐与 MIDI 的原始 0 秒对齐：MIDI 选 30–45 秒，也截取音乐的 30–45 秒。音乐比选区短时补静音，不自动循环，也不受每个音符的力度和结束事件切割。

### 音符怎样结束

默认保持 **“跟随延音踏板”不勾选**：例如 A 播放 0–2 秒、B 播放 1–3 秒，0–1 秒只放 A，1–2 秒同时放 A 和 B，2–3 秒只放 B。音符全结束后，画面黑屏；素材原声模式同时静音。

只有希望松开琴键后的音继续持续到踏板释放时，才勾选 **“跟随延音踏板”**。启用后，同时播放的声部和分屏可能明显增加；切换会同步更新时间轴、试听和导出。

v0.5.2 在素材声音起止及循环接缝加入最多 5 毫秒的平滑过渡，减少硬切产生的“啪”声。收尾在音符结束前完成，不延长音符；它不会清除素材本身已经录进去的噪声。**升级后要重新导出，旧成片不会自动改变。**

## 6. 常见问题

出现错误时，展开底部 **“查看错误详情”**，点 **“复制错误详情”** 保存完整文字；排查时同时记录版本、画面模式、选区和素材目录结构。

| 提示或现象 | 处理方法 |
| --- | --- |
| 双击没有打开窗口，或提示缺少 `VCRUNTIME140.dll` | 安装第 2 节链接的微软 Visual C++ v14 **x64** 运行库，再重试；确认使用 Windows 10/11 x64 的发布包。 |
| “请使用包含 EXE 的 Rust 版下载包” | 下载 Assets 中的 Windows 程序 ZIP，完整解压；不要用 Source code 包运行 `start.bat`。 |
| “找不到 FFmpeg”或“找不到指定的 FFmpeg” | 按第 2 节放置两个 EXE，或在“更多设置”重新选择真实存在的 `ffmpeg.exe`，不要选择 ZIP 或文件夹。 |
| “缺少以下音符的素材” | 核对报错列出的音名；选中目录应直接包含这些音名文件，或为标准正弦包根目录。新手直接选择 `videos` 最清楚。 |
| “有多个素材候选，请只保留一份” | 同一音高有重名或等音文件；把音频与视频分到不同文件夹，只保留实际想用的一份。 |
| “没有视频轨道” | 当前使用了 WAV 等纯音频素材。切换音名画面，或换成有视频轨道的 MP4 等素材。 |
| “所选素材没有可导出的音轨” | 素材没有声音；换带原声的素材，或导入完整音乐。静音源文件不能凭 MIDI 自动变成钢琴音。 |
| “时间范围应满足…”或“当前轨道、通道和时间范围没有可用音符” | 确认开始小于结束、范围不超过 MIDI 时长，至少勾选一个含音符的轨道；可先点“选择全曲”。 |
| “保存文件名应以 .mp4/.wav 结尾”或“保存位置需要包含文件名” | 选择完整文件名，例如 `成片.mp4`，不要只选一个文件夹；音频单独导出用 `.wav`。 |
| “无法替换输出文件；原输出仍保留” | 关闭正在打开该成片的播放器，或换一个新文件名；输出也不能覆盖当前正在使用的素材或导入音乐。 |
| 画面同时出现很多音符 | 确认未勾选“跟随延音踏板”，并检查轨道选择；真实和弦仍会分屏。只需单声部时，可选“仅最高音”“仅最低音”或“最后进入的音符”。 |
| 导出很慢或临时空间不足 | 原视频模式在复音多、网格变化多时需要更多处理中间文件。先用短选区、720p/30fps测试；只看音符可选音名快速模式，只要音乐就导出 WAV。给输出盘和系统临时目录所在盘保留足够空间，“更多设置”的并行任务先保持 0（自动），资源紧张时可试 2。 |
| 仍听到杂音 | 确认使用 v0.5.2 并重新导出；分别播放源素材与导出的 WAV，判断源文件是否已有杂音。若只有某个素材异常，替换该素材后重试。 |

中文文件名和路径可以使用。v0.5.2 已包含 Windows 扩展路径下最终拼接找不到中间文件的修复，不需要先把所有中文改成英文。

导出期间可点 **“取消任务”**；取消或失败不会替换原有输出。不要在处理时移动、改名或删除 MIDI、素材和导入音乐；源 MIDI 发生变化后需要重新读取。导出成功后再用 **“打开结果”** 或 **“打开目录”** 查看成片。
